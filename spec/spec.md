- 문서 버전: v0.1 (초안)
- 근거 자료: `2026-1학기 교육대학원 학사 & 교직 가이드` (숙명여대 교육대학원)
  - p.23~24 교육대학원 졸업자의 무시험검정 자격기준 / 2026년도 입학자 검정 기준표

  - p.28~29 교육봉사

## 1. 배경 / 목적

숙명포털의 **교직이수표**는 영역별 `충족 / 미충족`만 보여준다. "무엇을 더 들어야 충족되는지"를
알려주지 않기 때문에, 매 학기 수강신청 때마다 가이드 PDF와 교직이수표를 대조해야 한다.

이 페이지는 그 대조 작업을 대신한다.

> 들은 수업을 체크하면 → **남은 과목과 남은 조건을 문장으로 알려준다.**

## 2. 범위

### 2.1 포함

- 단일 HTML 페이지 1개 (SPA 아님, 프레임워크 없음)
- 2026학년도 입학자 / **컴퓨터교육전공(표시과목: 정보·컴퓨터) / 중등학교 정교사(2급)** 기준
- 교원자격 무시험검정 합격기준 체크리스트 + 영역별 잔여 안내
- 브라우저 로컬 저장(localStorage) — 서버·로그인 없음
- GitHub Pages 배포 (`docs/index.html`)

### 2.2 제외 (v1)

- 석사학위 수여요건(수료학점 24학점, 학위논문, 외국어시험 등) — 교직이수와 별개 트랙
- 타 전공(국어·수학·상담 등) 기본이수 표
- 계정·서버 저장·다중 기기 동기화

### 2.3 사용자

교직이수 중인 교육대학원생(현직 교사 포함). 각자 자기 브라우저에서 체크하며, 데이터는 공유되지 않는다.

## 5. 판정 규칙

### 5.1 항목 상태 (3-state)

각 과목 항목은 다음 세 상태를 가진다.

| 상태 | 의미 | 과목 수 인정 | 대학원 학점 인정 | 성적 평균 반영 |
| --- | --- | --- | --- | --- |
| `NONE` | 미이수 | X | X | X |
| `GRAD` | 교육대학원 이수 | O | O | O |
| `UNDERGRAD` | 학부 인정 | O | X | X |

- 교과교육영역 항목은 `UNDERGRAD` 선택 불가 (교육대학원 이수 필수).
- `UNDERGRAD`는 기본이수과목에만 적용한다.

### 5.2 영역별 충족 판정

```
교과교육영역   : 3과목 모두 GRAD                       → 충족
기본이수과목   : 그룹 (1) 2과목 + (2)~(6) 각 1과목      → 충족
                 (그룹별로 독립 판정, 전체는 AND)
교직이론       : 9개 중 (GRAD 개수) >= 6               → 충족
교직소양       : 4과목 모두 GRAD                       → 충족
교육실습       : 3항목 모두 GRAD 또는 '면제'            → 충족
비교과         : 항목별 요구 횟수 이상                  → 충족
```

### 5.3 잔여 안내 문구 생성 규칙

영역마다 "남은 일" 문장을 자동 생성한다.

- 필수 전량 영역: `남은 N과목: A, B, C`
- 택N 영역: `(2) 알고리즘/인공지능에서 1과목 필요 — 알고리즘교육론, 인공지능교육론 중 택1`
- 충족 영역: `충족 — 더 들을 과목 없음`
- 교육실습: 면제 토글이 켜져 있으면 `교원자격증 소지 면제 적용` 표기
- 성적/학점처럼 사용자가 입력해야 판정 가능한 항목은 `입력 필요` 상태를 따로 둔다.

### 5.4 학점 집계

- 각 과목은 2학점으로 계산한다(교육봉사1·2는 1학점, 학교현장실습 2학점).
- 전공 50학점 / 교직 23학점 총량은 체크만으로는 채워지지 않는다(전공 선택과목 포함).
  → **현재 전공 이수학점 직접 입력 필드**를 두고 `입력값 / 50` 으로 표시한다. *(→ 오픈 이슈 O-2)*

## 6. 화면 요구사항

단일 페이지, 위에서 아래로 스크롤. 라우팅 없음.

### 6.1 구성

```
┌─ 헤더 ────────────────────────────────────────┐
│ 제목 / 기준 연도 · 전공 표기 / 전체 진행률 바   │
├─ 요약 패널 ───────────────────────────────────┤
│ 영역별 충족·미충족 배지 (교직이수표 총괄표와 동일 구성) │
│ "지금 남은 일" 상위 3~5줄 요약                  │
├─ 섹션 1. 전공 — 교과교육영역 ─────────────────┤
│ 체크리스트 + 우측(또는 하단) '남은 일' 설명 박스 │
├─ 섹션 2. 전공 — 기본이수과목 (그룹 (1)~(6)) ──┤
├─ 섹션 3. 교직이론 (택6/9)                      │
├─ 섹션 4. 교직소양 (필수 4)                     │
├─ 섹션 5. 교육실습 · 교육봉사 (+면제 토글)      │
├─ 섹션 6. 비교과 (적인성/응급처치/성인지)       │
└─ 푸터: 근거 출처, 마지막 수정일, 초기화 버튼 ──┘
```

### 6.2 세부 요구

- **각 섹션에는 '남은 일' 설명 공간을 반드시 둔다** (핵심 요구사항).
  체크 상태가 바뀌면 즉시 문장이 갱신된다.
- 항목별로 다음을 표시: 과목명, 학수번호(있으면), 학점, 상태 선택 UI, **개인 메모**(1줄).
  - 메모 예: `2학기 예정`, `1학기 이수 완료`, `인정전공(논리회로)으로 인정`
- 진행률: 영역별 `이수 n / 필요 m`, 전체 진행률.
- 미충족 항목은 색으로 구분(충족/미충족/예정). 색만으로 구분하지 않고 텍스트 라벨 병행.
- 모바일(폭 360px 이상)에서 1단 레이아웃으로 동작.
- 인쇄 시 체크 상태가 그대로 보이도록 print 스타일 최소 대응.

### 6.3 상태 저장

- `localStorage` 단일 키에 JSON 저장. 스키마 버전 필드 포함.
- 저장 실패(사생활 보호 모드 등)해도 페이지는 정상 동작해야 한다.
- `내보내기 / 가져오기`(JSON 텍스트 복사·붙여넣기)로 기기 간 이동 지원. *(→ 오픈 이슈 O-3)*
- `초기화` 버튼은 확인 후 실행.

## 9. 디렉토리 · 배포

```
spec/   요구사항·정책 문서 (이 문서)
src/    웹 페이지 소스 (index.html, styles.css, app.js, data/requirements.json)
docs/   빌드 산출물 — GitHub Pages 게시 대상 (docs/index.html)
```

- 빌드: `src`의 CSS/JS/데이터를 **단일 `docs/index.html`로 인라인**한다.
  (파일 1개면 GitHub Pages 경로·MIME 이슈가 없고, 로컬에서 파일을 열어도 그대로 동작)
- GitHub Pages 설정: `main` 브랜치 `/docs` 폴더.
- 빌드 스크립트는 Node 없이 동작하는 셸 스크립트 또는 최소한의 Node 스크립트. *(→ 오픈 이슈 O-4)*
