## 2. 요건 데이터

### 2.1 전공과목 (50학점 이상)

교과교육영역이 없다. 전공은 **기본이수과목 + 전공선택(교과내용영역)** 으로만 채운다.

교육부 지정 기본이수과목 중 **아동심리학 · 직업교육론 · 직업정보 · 진로지도 · 학습심리학**은
우리 교육대학원에 개설과목이 없다.
`임상심리학`은 개설과목은 없지만 **학부 이수분을 학점인정서로 기본이수 인정**받을 수 있어 항목으로 둔다
(상태는 사실상 `학부 인정`만 가능).

- 개설과목이 없는 지정과목은 **화면에 표시하지 않는다.** 우리 교육대학원에서 이수할 수 없다.
- 체크 가능한 인정과목은 (1) 상담실습 + (2) 11과목 = **12개**.
- **(1) 상담실습은 교직과목을 이수하면 면제받을 수 있다.** 면제 토글을 (1)영역에만 거는 그룹 단위 면제로
  구현한다(spec.md 5.2.1). 면제 시 상담실습 2학점은 붙지 않으므로 전공선택 과목이 1개 더 필요해진다.
- `상담실습`은 2026학년도 입학자부터 필수이나 2026. 8. 3. 기준 아직 `개설예정`이라 학수번호가 없다.
  화면에는 항목으로 두되 `개설예정 — 학수번호 미정` 을 붙인다. *(→ 오픈 이슈 P-1)*
- 학위자격시험으로 졸업하려는 26학번 이후 학생은 `심리검사실습`, `이상심리`, `상담이론과실제` 3과목이
  필수다. 세 과목 모두 기본이수과목이기도 하므로 화면에 비고로 표시한다.

## 3. 판정 규칙

spec.md 5장을 따르되 아래만 다르다.

```
교과교육영역   : 섹션 자체가 없다
기본이수과목   : (1) 상담실습 1과목 필수 + (2) 6과목 이상  → 충족
전공선택       : 1과목 이상 (상담실습 면제 시 2과목)         → 충족
전공 이수학점  : 34 + (기본이수 중 GRAD 과목 수) x 2
```

- 교과교육영역이 없으므로 전공 학점 계산의 가산 대상은 **기본이수과목뿐**이다.
- 학부 기본 인정학점은 컴퓨터교육전공과 같은 **34학점**이다.
  교과교육영역(6학점)이 없으므로 기본이수만 채우면 `34 + 7과목 x 2 = 48학점`이고,
  전공선택 1과목을 더해야 `50학점`이 된다.
- 항목 3-state(`NONE` / `GRAD` / `UNDERGRAD`)와 학부 인정 취급은 동일하다.

## 4. 데이터 · 파일 구조

요건 데이터만 분리하고 코드는 공유한다.

```
src/data/requirements.json             컴퓨터교육전공 (기존)
src/data/requirements-psychology.json  상담교육전공 (신규)
```

- `sections` 배열에서 `subject-pedagogy`(교과교육영역)를 제거하고 `basic-courses`를 상담교육 표로 교체한다.
- `teaching-theory` / `teaching-literacy` / `practicum` / `extracurricular` 는 컴퓨터교육 데이터와 동일하다.
- `credits.undergradBase` 는 컴퓨터교육전공과 동일하게 **34학점**이다.
- **`storageKey` 를 전공별로 분리한다.** 두 페이지가 같은 오리진(`rarelhw.github.io`)이고
  교직과목 항목 id가 공유되므로, 키를 나누지 않으면 한쪽 체크가 다른 쪽에 그대로 나타난다.
  - 컴퓨터교육: `sm-teaching-checklist:v1` (기존 값 유지 — 저장된 체크를 잃지 않기 위해)
  - 상담교육: `sm-teaching-checklist:psychology:v1`
- 빌드는 같은 `src/index.html` 템플릿으로 두 페이지를 찍는다
  (`docs/index.html`, `docs/psychology.html`). 상단 탭으로 서로 이동한다.

## 부록. 전문상담교사(1급) 트랙

2급과 별개 트랙이다. **입학 전에** 2급 이상 교원자격증 + 해당 자격증에 맞는 교육경력 3년 이상이 있어야 신청할 수 있고,
자격증은 교육청에서 본인이 직접 발급 신청한다. 교육대학원은 **이수증명서**만 발급한다.

### 이수 요건

| 구분 | 요건 | 인정과목 (학수번호) |
| --- | --- | --- |
| 필수 | 7과목 14학점 이상 | 21023151 심리검사실습 · 21023152 성격심리 · 21023353 특수아상담 · 21023149 집단상담실습 · 21023154 가족상담 · 21023153 진로상담지도 · 21023160 상담이론과실제 *(발달심리는 개설 없음)* |
| 필수 | 상담실습및사례연구 | 21023161 상담실습및사례연구 |
| 선택 | 2과목 4학점 이상 | 21023156 아동발달 · 21023159 이상심리 · 21023155 생활지도연구 · 21023157 청년발달 · 21024132 사이버상담 · 21060926 성상담실습 · 21060933 학습상담 · 21060925 심리학개론 · 21060935 인간관계론 · 21024288 특수교육학개론(공통) |
| 비교과 | 2급과 동일 (적인성 2회 · 응급처치 2회 · 성인지 2회, 마약류·성범죄 결격 없을 것) | — |

- `상담실습및사례연구`: 2종 이상 사례연구·발표 + **20시간 이상 실습**(1종당 10시간),
  수강 후 사례연구보고서 2종을 교학팀에 제출. 우리 교육대학원은 2학점 교과목으로 운영하며 전공학점으로도 인정된다.
- 수료학점이 다르다: 공통 1과목(2학점) + 전공 11과목(22학점) + 연구방법론(0학점).
  학위자격시험으로 졸업하면 6학점을 추가 이수해 30학점을 채워야 한다.
- 2015학년도 입학자부터 1급 선발인원이 교원양성 승인인원에 포함되어, **1급 취득 목적으로 입학하지 않았으면 이수증명서를 발급하지 않는다.**

### 학위 관련 (2급·1급 공통)

- 상담교육전공은 학위논문과 학위자격시험 **둘 다** 가능하다.
- 2026학년도 신입생 중 **학위자격시험**으로 졸업하려는 상담교육전공(1급·2급) 학생은
  `상담이론및실제`, `이상심리`, `심리검사실습` **3과목을 입학 후 필수 이수**해야 한다.
- 이는 교직이수 요건이 아니라 석사학위 요건이므로 체크리스트 v1 범위에서는 제외한다.
